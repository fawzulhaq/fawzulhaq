# 🛡️ Fawzul Haq – Cybersecurity Portfolio

> **Live Site:** [https://fawzulhaq.github.io/fawzulhaq](https://fawzulhaq.github.io/fawzulhaq)

A professional cybersecurity-themed portfolio for **M.N.M. Fawzul Haq** – System Engineer & Cybersecurity Enthusiast.

## 🚀 Features

- **Matrix Rain** animated background
- **Interactive Terminal** typewriter simulation
- **Skill Bar Animations** with intersection observer
- **Radar Animation** threat visualization
- **Downloadable CV** as PDF
- **Fully Responsive** mobile-first design
- **GitHub Pages Ready** with automated deployment

Dark cyberpunk aesthetic with:
- Neon green (#00ff88) / Cyan (#00d4ff) accent colors
- JetBrains Mono terminal font
- Orbitron display font
- Glassmorphism cards
- Animated hex grid

## 📂 Structure

```
portfolio/
├── index.html          # Main HTML
├── style.css           # Styles
├── main.js             # Interactive JS
├── fawzulhaq_cv.pdf    # CV for download
└── .github/
    └── workflows/
        └── deploy.yml  # Auto-deploy to GitHub Pages
```

## 🌐 Hosting on GitHub Pages

1. Push this repository to `github.com/fawzulhaq/fawzulhaq`
2. Go to **Settings → Pages**
3. Set source to **GitHub Actions**
4. The workflow will auto-deploy on every push to `main`

## 📝 Updating CV

Replace `fawzulhaq_cv.pdf` with your updated PDF file and push to `main`.
